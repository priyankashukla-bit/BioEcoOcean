# BioEcoOcean

Remote‑sensing and machine‑learning workflows for coastal and marine habitat
mapping, developed for **BioEcoOcean** / **AIR Centre**.

## Projects

| Project | Description |
|---------|-------------|
| [`viana_de_castelo_seaweed_classification`](viana_de_castelo_seaweed_classification/) | Random‑Forest classification of intertidal **Rock vs Seaweed** from a Sentinel‑2 low‑tide composite at Viana do Castelo, NW Portugal — probability, confidence and area products with publication‑quality maps. |
